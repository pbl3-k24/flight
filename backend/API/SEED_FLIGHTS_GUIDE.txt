## MỤC ĐÍCH
Tạo dữ liệu mẫu đầy đủ cho hệ thống đặt vé máy bay bao gồm:
- FlightDefinitions: Định nghĩa chuyến bay (số hiệu, giờ bay, tuyến đường)
- Flights: Chuyến bay thực tế cho 30 ngày tới
- FlightSeatInventories: Kho ghế cho mỗi chuyến bay

## CÁC FILE LIÊN QUAN

1. seed_flight_definitions_and_flights.sql
   - File SQL chính chứa tất cả logic tạo dữ liệu
   - Tự động tạo ~600 chuyến bay cho 30 ngày tới

2. run_seed_flights.ps1
   - Script PowerShell để chạy file SQL
   - Tự động kết nối database và thực thi

3. create_missing_tables.sql
   - Tạo bảng FlightDefinitions nếu chưa có
   - Chạy file này TRƯỚC nếu bảng chưa tồn tại

### Flights (~600 records)
- Tự động tạo cho 30 ngày tới
- Mỗi FlightDefinition tạo 1 Flight/ngày (nếu hoạt động)
- Ví dụ: VN201 sẽ có 30 flights (mỗi ngày 1 chuyến)

### FlightSeatInventories (~1800 records)
- Mỗi Flight có 3 hạng ghế (Economy, Business, First Class)
- Số ghế và giá lấy từ AircraftSeatTemplates
- Tất cả ghế đều available ban đầu

## OPERATING DAYS (Ngày hoạt động)

OperatingDays là một số nguyên biểu diễn các ngày trong tuần:
- 1 = Monday
- 2 = Tuesday
- 4 = Wednesday
- 8 = Thursday
- 16 = Friday
- 32 = Saturday
- 64 = Sunday

**Ví dụ:**
- 127 = 1+2+4+8+16+32+64 = Hàng ngày
- 31 = 1+2+4+8+16 = Thứ 2-6 (Mon-Fri)
- 96 = 32+64 = Cuối tuần (Sat-Sun)

## KIỂM TRA DỮ LIỆU

### Đếm tổng số records:
```sql
SELECT 'FlightDefinitions' as "Table", COUNT(*) FROM "FlightDefinitions"
UNION ALL
SELECT 'Flights', COUNT(*) FROM "Flights" WHERE "FlightDefinitionId" IS NOT NULL
UNION ALL
SELECT 'FlightSeatInventories', COUNT(*) FROM "FlightSeatInventories";
```

### Xem flights hôm nay:
```sql
SELECT 
    fd."FlightNumber",
    f."DepartureTime",
    f."ArrivalTime",
    sc."Name" as "SeatClass",
    fsi."AvailableSeats",
    fsi."BasePrice"
FROM "Flights" f
INNER JOIN "FlightDefinitions" fd ON f."FlightDefinitionId" = fd."Id"
INNER JOIN "FlightSeatInventories" fsi ON fsi."FlightId" = f."Id"
INNER JOIN "SeatClasses" sc ON sc."Id" = fsi."SeatClassId"
WHERE DATE(f."DepartureTime") = CURRENT_DATE
ORDER BY f."DepartureTime", fd."FlightNumber";
```

### Xem thống kê theo ngày:
```sql
SELECT 
    DATE(f."DepartureTime") as "Date",
    COUNT(*) as "TotalFlights"
FROM "Flights" f
WHERE f."FlightDefinitionId" IS NOT NULL
GROUP BY DATE(f."DepartureTime")
ORDER BY DATE(f."DepartureTime");
```

## XÓA DỮ LIỆU (NẾU CẦN)

```sql
-- Xóa tất cả dữ liệu liên quan
DELETE FROM "FlightSeatInventories" 
WHERE "FlightId" IN (
    SELECT "Id" FROM "Flights" WHERE "FlightDefinitionId" IS NOT NULL
);

DELETE FROM "Flights" WHERE "FlightDefinitionId" IS NOT NULL;
DELETE FROM "FlightDefinitions";
```

## LƯU Ý QUAN TRỌNG

1. **Yêu cầu trước khi chạy:**
   - Bảng Routes phải có dữ liệu (RouteId 1-4)
   - Bảng Aircraft phải có dữ liệu (AircraftId 1-3)
   - Bảng SeatClasses phải có dữ liệu
   - Bảng AircraftSeatTemplates phải có dữ liệu

2. **Script sẽ tự động:**
   - Tạo bảng FlightDefinitions nếu chưa có
   - Xóa dữ liệu cũ trước khi insert
   - Tạo flights cho 30 ngày tới
   - Tạo seat inventory cho mỗi flight

3. **Thời gian chạy:**
   - Khoảng 5-10 giây để tạo ~2400 records

4. **Chạy lại script:**
   - An toàn để chạy nhiều lần
   - Sẽ xóa và tạo lại dữ liệu mới

## TROUBLESHOOTING

### Lỗi: "relation FlightDefinitions does not exist"
→ Chạy file create_missing_tables.sql trước

### Lỗi: "foreign key violation"
→ Kiểm tra Routes, Aircraft, SeatClasses có dữ liệu chưa

### Lỗi: "duplicate key value"
→ Chạy phần DELETE trước để xóa dữ liệu cũ

### Không có flights được tạo
→ Kiểm tra AircraftSeatTemplates có dữ liệu chưa
