================================================================================
                            DỮ LIỆU ĐƯỢC TẠO
================================================================================

FlightDefinitions: ~20 records
├─ HAN → SGN: 8 chuyến/ngày (VN201-211, VJ123-125)
├─ SGN → HAN: 7 chuyến/ngày (VN202-210, VJ124-126)
├─ HAN → DAD: 2 chuyến/ngày (VN301, VN303)
├─ DAD → HAN: 2 chuyến/ngày (VN302, VN304)
└─ Overnight: 1 chuyến (VN999)

Flights: ~600 records
└─ Mỗi FlightDefinition × 30 ngày = 600 flights

FlightSeatInventories: ~1,800 records
└─ Mỗi Flight × 3 seat classes = 1,800 records

================================================================================
                            KIỂM TRA NHANH
================================================================================

# Đếm số records
SELECT 
    'FlightDefinitions' as "Table", COUNT(*) as "Count"
FROM "FlightDefinitions"
UNION ALL
SELECT 'Flights', COUNT(*) FROM "Flights" WHERE "FlightDefinitionId" IS NOT NULL
UNION ALL
SELECT 'FlightSeatInventories', COUNT(*) FROM "FlightSeatInventories";

# Xem flights hôm nay
SELECT 
    fd."FlightNumber",
    TO_CHAR(f."DepartureTime", 'HH24:MI') as "Time",
    COUNT(fsi."Id") as "SeatClasses"
FROM "Flights" f
INNER JOIN "FlightDefinitions" fd ON f."FlightDefinitionId" = fd."Id"
LEFT JOIN "FlightSeatInventories" fsi ON fsi."FlightId" = f."Id"
WHERE DATE(f."DepartureTime") = CURRENT_DATE
GROUP BY fd."FlightNumber", f."DepartureTime"
ORDER BY f."DepartureTime";

================================================================================
                            TROUBLESHOOTING
================================================================================

❌ "relation FlightDefinitions does not exist"
   → Chạy: create_missing_tables.sql

❌ "foreign key violation"
   → Kiểm tra Routes, Aircraft, SeatClasses có dữ liệu chưa

❌ Không có flights được tạo
   → Kiểm tra AircraftSeatTemplates có dữ liệu chưa

❌ "duplicate key value"
   → Dữ liệu đã tồn tại, script sẽ tự động xóa và tạo lại

================================================================================
                            OPERATING DAYS
================================================================================

OperatingDays là một số nguyên biểu diễn các ngày trong tuần:

Monday    = 1
Tuesday   = 2
Wednesday = 4
Thursday  = 8
Friday    = 16
Saturday  = 32
Sunday    = 64

Ví dụ:
------
127 = 1+2+4+8+16+32+64 = Hàng ngày (Every day)
31  = 1+2+4+8+16       = Thứ 2-6 (Mon-Fri)
96  = 32+64            = Cuối tuần (Sat-Sun)
